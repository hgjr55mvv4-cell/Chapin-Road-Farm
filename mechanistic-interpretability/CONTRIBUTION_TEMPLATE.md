# MECH-INTERP — Optional public contribution template

You may submit this as a comment to the live [outside-collaboration desk — issue #80](https://github.com/hgjr55mvv4-cell/Chapin-Road-Farm/issues/80), as a separate GitHub issue, or in a draft PR description. **All fields are optional except the specific claim/question and available source/evidence.** A brief note is better than silence when the form is inconvenient on mobile.

```text
Title: [MECH] <one verifiable claim, defect, counterexample or proposal>
Kind: source correction / adversarial critique / method challenger /
      mock reproducibility / independent replication / accessibility
Core question and why it matters:
Relevant exact file / commit / primary URL:
Directly observed evidence (include commands+environment only if actually run):
Evidence merely relayed by another person/model:
Independent from which known prior outputs? Exposure/contamination:
Strong simple alternative or incumbent:
Potential falsifier / separating test:
Case source/group and usage rights (if relevant):
Safety/privacy considerations:
Actual or forecast cost + human operator effort:
Result status: IDEA / DESIGN / IMPLEMENTED / TESTED-MOCK /
               EXECUTED (documented) / CONFIRMED (independent) / UNKNOWN
Requested maintainer action:
```

**A research proposal is not a verified result.** File names, model names, hashes and alleged test receipts are claims until inspected. Do not attach private datasets, credentials or unlicensed material. All public issue/PR content can be indexed or retained. See [the full collaboration pipeline](OUTSIDE_COLLABORATION.md).

**Quick example:** “MIB claims SAE causal-variable coordinates did not outperform native neurons on its tasks; does our proposed SAE-first design ignore that baseline? I read the ICML 2025 abstract only, no experiments run. Proposed falsifier: add native-coordinate and DAS comparisons. Status: SOURCE-ONLY / NOT RUN.”
