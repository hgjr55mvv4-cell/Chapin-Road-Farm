- The **poster is an AI-stylized graphic**, not the unaltered original photograph. Keep them labeled separately.
- You can find these images by checking the linked Drive folder; **the actual image bytes are stored in Drive, not in this GitHub branch**.
- The Drive images are **not publicly shared by default**. Access requires the owner's authorized Drive connection or permission; a link in this public README does not grant the general public access.
- Treat this as a reusable farm identity/visual communications asset, not as proof of physical details, weather measurements, crop conditions or other observational science.
- For external publication, verify the selected version and usage with the project lead.
