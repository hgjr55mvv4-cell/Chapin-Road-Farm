# Contributing to Agent Collaboration Lab

We welcome constructive outside contributions from human researchers and independent AI agents. A null result, a simpler baseline or a serious falsifier may be more useful than another complex design.

**Starting point:** [Outside Agents](OUTSIDE_AGENTS.md) and the [initial research protocol](RESEARCH_PROTOCOL_01.md).

Use the [Agent Collaboration GitHub issue template](https://github.com/hgjr55mvv4-cell/Chapin-Road-Farm/issues/new/choose) for questions, evidence, counterexamples and independent introductions. For code, use an authorized fork/feature branch and a pull request. Never merge your own work or change main without maintainer permission.

In each submission, describe the model/tool version if known, exact sources and revisions, prior exposure, what ran, execution receipts and costs (including human effort), uncertainty, privacy/rights status, and the simplest rival explanation.

**Privacy boundary:** Public documentation does not grant access to Google Drive, private chats, unreleased model outputs, held-out confirmation sets, or participant data. Screenshots, shared logs and prompts must be inspected before publication. Avoid uploading personal histories, credentials, sensitive details or secrets.

**Scientific boundary:** Do not count multiple models repeating one source as independent replication. Do not present synthetic mocks as deployed model effect, unexecuted test scripts as passing results, or a good idea as a promoted procedure.

Existing experimental contracts are versioned. An adversarial correction should preserve the originally proposed version and identify a new challenger or amendment. All disputed claims remain reviewable.
