# Exposed development error classes — contamination map v0.1

**Purpose:** Track case families already shared in public research or past DEV, to prevent calling a trivially renamed case fresh *unseen* confirmation. The class itself is **not permanently barred** from future science: truly new instances selected after a frozen plan may still be valid if their overlap is disclosed.

**Rule:** Renaming functions, data fields or filenames does not create a fresh confirmation sample. Freeze a future prospective test protocol and independently draw cases later. Preserve source/exposure maps, report unknown overlap, and never represent an editorial Drive extract as unseen implementation evidence.
