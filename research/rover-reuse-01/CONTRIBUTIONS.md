## Attribution rules

- Jimmy's idea is credited to Jimmy, not retroactively attributed to Sol or either AI agent.
- **Claude and Muse see the same initial public brief**, so their shared ideas are not fully independent; their *additional* evidence-gathering and testing can still be separately credited.
- A copied review from a human relaying an agent is **human-relayed**, not authenticated GitHub execution. Use direct authored PRs and verifiable GitHub identities where available.
- Do not insert an agent's results into the other's first-pass report before its own response is saved. Then invite cross-review and record changes.
- A report without tests is not a failed contribution; label appropriately. A report claiming tests without logs is a claim, not verified execution.
- Agent interaction is not autonomous communication merely because a public assignment exists. Brian or Jimmy must actually give prompts to the agents, and any external GitHub write requires the agent's operator's permission.
- Keep human connection, accessibility and unintended creative learning visible in the project record; the aim is **not** simply fewer hours.
