# TLR-ROUND-02 — Community Listening & Continuous Learning

**Status:** exploratory design. No participant recruitment, real data collection, audio upload, model training, public intake or scientific confirmation authorized.

## Four-model sequence

1. **Muse** — Discover what makes a useful, optional listening contribution; review qualitative methods, representational fairness, listener voice, and participant burden. Deliver a draft listening diary and consent-tier design.
2. **Grok** — Adversarial challenge: selection bias, performative reports, cultural overgeneralization, privacy/de-anonymization, temporal and sonic inference, and bad recommenders that flatter listeners.
3. **DeepSeek** — Minimal computational model for playlist-group observations, cross-genre similarity hypotheses, provenance-aware feature extraction only from authorized audio, and longitudinal evaluation with leakage controls.
4. **Claude** — Integrate reviewed contracts into a minimal app increment; do not presume Sprint 01 exists until independently delivered and examined.

## Separate learning loops

- **Personal:** a listener can permit correction-aware preference learning in their own app. Private associations are opt-in and their deletion must be honored within defined technical limits.
- **Research:** separately volunteered, explicitly scoped, de-identified or synthetic materials may support scientific evaluation only after a reviewed intake protocol exists.
- **Procedural:** recommender or UI changes are frozen challengers, tested against a simpler incumbent with quality, safety and cost floors (Ω-ARENA). No automatic promotion.

## Early falsifiable comparison

Within-person cross-genre meaningful playlist vs. equally diverse playlist selected without a meaning prompt. Compare verified audible features using independent source recordings, then compare listener-reported connecting concepts separately. Control for artist, familiarity, era, genre, production, prompt effects and playlist-selection bias. Do not interpret a clustering algorithm's attractive visualization as confirmation that it found personal meaning.

## Decision gates

Before accepting real listening contributions: ethics/privacy review, understandable separate consent for storage/publication/research/model training, functional withdrawal and export, copyright and sensitive-culture safeguards, retention rules, secure non-GitHub intake, vulnerability review, and explicit operator burden. Initial GitHub release should publish only code and synthetic fixtures.
