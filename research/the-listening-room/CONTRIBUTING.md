# Contributing to The Listening Room (research staging)

We welcome contributions to the *design* of the open-source application, data formats, privacy protections, test fixtures, accessibility, music-knowledge provenance, and research evaluation.

## Safe contributions now
- Improve the schema or propose deterministic software tests.
- Challenge the research method or selection-bias assumptions.
- Suggest rights-cleared sources of track metadata or research audio.
- Propose accessibility improvements and feedback controls.
- Use invented, explicitly **synthetic** examples with no connection to real people's private histories.

## Not yet authorized
- No volunteer recruitment or survey enrollment through this branch.
- Do **not** paste genuine playlists linked to a named person, listening diaries, private memories, health information, relationship details or sensitive cultural knowledge into public GitHub posts.
- Do not upload copyrighted recordings, stems, transcriptions, full lyrics, user accounts, access tokens, or scraped streaming data.
- Do not treat a publicly visible comment as informed consent for research reuse, training, or redistribution.

## Evidence boundaries
Label all fields as source metadata, user report, verified audio observation, or inference. A track-level genre or instrument tag does not verify a musical event at a specific timestamp.

Public code licensing and data-sharing permission are separate decisions. Neither a GitHub contribution nor a software license should be interpreted as participant consent.

## Review discipline
Research is exploratory. Any durable product/recommendation policy proposed from this work is a versioned Ω-ARENA challenger and must be frozen and independently tested against a valid baseline before promotion.

**Current status:** Documentation and synthetic-schema proposals only. Real listener submissions are not accepted by this repository.
