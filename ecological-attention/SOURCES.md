# Source audit queue and boundaries

This is an initial bibliography and audit list, **not** an assertion that all historical interpretations or scientific mechanisms are verified.

## Grounded bibliographic starting points
- **Xunzi, chapter 解蔽 (Jie Bi / Resolving Obsession).** Chinese source text is available via [Chinese Text Project](https://ctext.org/xunzi/jie-bi). The phrase 凡人之患，蔽於一曲，而闇於大理 appears in that text. The interpretation as a machine-attention design principle is contemporary and speculative. Modern translation should be attributed to a named translator, not treated as an ancient English quotation.
- **Kenneth J. Arrow and Anthony C. Fisher (1974),** “Environmental Preservation, Uncertainty, and Irreversibility,” *Quarterly Journal of Economics* 88(2): 312–319, [DOI 10.2307/1883074](https://doi.org/10.2307/1883074). A bibliographic anchor for irreversibility under uncertainty, **not** verification that any proposed AI pause helps.
- **Zhuangzi, Laozi/Daodejing, Zhang Zai, Qimin Yaoshu.** Discussed in relayed model dialogue; passage editions, translation attribution and interpretive limitations need scholarly checks before they are quoted as authoritative project claims.

## Questions for research audit
1. Which philosophical passages are primary-source supported, and which modern readings overclaim conservation implications?
2. Which classic/open-set, event detection or motion baselines are the strongest credible technical incumbents for EXP-001?
