# Physical bench falsification plan — NOT EXECUTED
**Authority:** design only; $0 additional spending; existing safe tabletop equipment only. Do not install on an operating tractor, engine, transmission, implement or other machine. **Never add indicator dyes to working machine fluids.**

### Hypotheses to prove separately
1. A cantilever with captive tip mass can be tuned to a repeatable resonance and visibly moves more for sustained near-band excitation than equal-acceleration off-band excitation.
2. A safe, one-way, no-power physical flag/latch can register the event and preserve the reading for 24h. A 12-extrema accumulating ratchet is currently **unbuilt** and might be too complex.
3. The indicator, with independently measured input acceleration, rejects appropriate short impacts and high-amplitude off-band negatives at acceptable cost.
4. Matched normal machinery conditions can be separated from genuine actionable anomalies; currently *unknown*.

### Test conditions
Use a guarded stationary fixture, captive parts, no open spinning hardware/high temperature/pressurization. Start without a latch; document dimensions, mass, mount, orientation, photograph, frequency/acceleration reference accuracy and uncertainty. Run measured amplitude-matched sweeps (normal, near-band, far-band), brief pulses, harmonics, repeat mountings. Do not infer calibrated g performance from an unvalidated phone. If a viable flag exists, conduct 20 resets/activations, blinded visual reads, 24h no-power memory and repeated temperature/orientation checks within a safe range. Record operator minutes/material costs.

### Hard STOP
Any unsecured component, instability, risk of ejection, broken spring, false reading under normal controls, unexplained drift or inability to distinguish arm state. Bench hardware **NOT RUN**, mechanical actuation **NOT VERIFIED**, diagnostic quality **UNKNOWN**. Freeze measured hardware settings before independent test cases. Compare against simple untuned peak threshold and tuned peak latch, not only the more complex dwell proposal.
